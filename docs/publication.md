# 发布包与私密状态

源码仓库及 Release ZIP 仅包含审阅过的脚本、配置模板、配对工具源码、说明文档与自编译程序。第三方安装器/APK 由官方链接和 SHA-256 锁定，不镜像到仓库。

禁止发布：完成后的管理凭据、Windows 密码、Auth key、`sunshine_state.json`、配对证书/私钥、DPAPI 密文、Clash 订阅和配置、原始安装日志、运行状态及本机真实设备标识。`.gitignore` 是辅助保护，不能替代发布前检查。

`Test-Package.ps1` 检查公开源码的语法、模板、明显凭据格式及不应包含的文件；`Build-Package.ps1` 从明确目录清单构建 ZIP，根目录下载缓存和本机报告不会被收集。发布前还应使用自己的真实敏感值进行本机扫描，只输出匹配位置，不输出敏感值。

Release ZIP 附 SHA-256，解压后可重新运行测试和编译脚本。完整依赖安装包需运行下载脚本从官方来源获取，因此首次部署需要可访问官方源的网络；离线部署请预先在受控本地目录准备通过校验的依赖，禁止把私密状态混进公开 ZIP。

复原已有配对属于私密备份恢复，不能从公开模板恢复原设备身份。新机器须重新登录、设置自己的管理密码并首次配对。
